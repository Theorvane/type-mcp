# Task brief — MCP TypeScript SDK v2 migration

**Owner:** Codex

**Date:** 2026-08-27

**Status:** complete

**Related plan:** GitHub issue `#176`

## Objective

TypeMCP runs on the stable split MCP TypeScript SDK v2 while preserving its
public package subpaths and existing decorated-server behavior.

## Scope

**In:**

- stable official v2 server/core runtime packages and client test dependency
- core type imports, compiler, stdio, and Fetch Streamable HTTP adaptation
- 2025 compatibility plus 2026 protocol lifecycle integration coverage
- root/http/langchain/legacy ESM, CommonJS, and declaration compatibility
- package, architecture, API, and migration documentation

**Out:**

- prompt arguments, resource templates, invocation context, visibility, helpers, and tasks
- OAuth/authorization policy, providers/proxies, OpenAPI generation, and MCP Apps

## Acceptance criteria

- [x] Production source and manifest no longer reference the monolithic v1 SDK.
- [x] Existing decorators, compilation, transports, safe errors, and metadata remain compatible.
- [x] The server negotiates supported 2025 and 2026 protocol lifecycles through official v2 APIs.
- [x] All public entrypoints verify in ESM and CommonJS consumers.
- [x] Full verification and production audit pass.
